# Template de Decisão Rápida

Para decisões que não exigem uma ADR completa, mas precisam de rastreabilidade.

```markdown
### Decisão de Frontend: [Título Curto]
- **Data:** [Data]
- **Contexto:** [O que motivou a decisão?]
- **Decisão:** [O que foi implementado/mudado?]
- **Racional:** [Por que esta abordagem?]
- **Impacto:** [O que muda no código/interface?]
```
